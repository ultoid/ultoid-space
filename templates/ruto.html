Pengaturan Ruto

Model provider

Provider Gemini menyediakan pilihan Gemma di sini. Untuk provider lain, model diatur melalui konfigurasi `.env`.

Penggunaan AI

Statistik ini menghitung semua request Ruto, termasuk request tambahan untuk memperbarui ringkasan chat memory. Isi batas RPD model dari dashboard provider untuk melihat estimasi lokal; angka ini bukan pembacaan kuota akun provider.

Lihat limit AI Studio

Core memory

Memori dasar tetap dan bisa kamu edit, termasuk panduan Nusvanir dan rujukan kanonis: https://github.com/ultoid/nusvanir. Disimpan sebagai data/ruto/core_memory.md.

Chat memory

Ruto memperbarui ringkasan tiap percakapan setelah setiap balasan menggunakan satu request AI tambahan. Ringkasan relevan dipakai sebagai konteks di chat berikutnya dan tetap tersimpan saat riwayat chat dihapus. Ini memori berbasis pencarian konteks, bukan pelatihan ulang model.

Skills

Setiap skill disimpan sebagai file Markdown terpisah. Kamu bisa menambah manual, mengimpor file .md, atau menyimpan jawaban chat sebagai skill.
